# Knowledge Graph

Generated by [graphify](https://github.com/safishamsi/graphify) from the Kernel Borderlands codebase and docs (`kb-core/include/vmlinux.h`'s vendored kernel struct definitions excluded via [`.graphifyignore`](../.graphifyignore) — they drowned out the project's own architecture).

## Files

| File | What it is |
| --- | --- |
| [`graph.html`](graph.html) | Interactive graph — open directly in a browser, no server needed. Also linked from the project landing page ([`docs/index.html`](../docs/index.html), nav "Graph" / footer "Knowledge Graph"). |
| [`GRAPH_REPORT.md`](GRAPH_REPORT.md) | Audit report: god nodes, surprising connections, hyperedges, suggested questions, per-community breakdown. |
| [`graph.json`](graph.json) | Raw graph data (nodes, edges, communities) — GraphRAG-ready. |

Everything else in this directory (`cache/`, `cost.json`, `manifest.json`, `transcripts/`) is local build state used for incremental `--update` runs and is gitignored.

## Stats

1,924 nodes · 3,146 edges · 178 communities, spanning `kb-core`, `kb-control-plane`, `kb-aads`, `kb-checker`, `kb-op`, and `docs/`.

## Publishing to GitHub Pages

GitHub Pages is configured to serve from `docs/`, not the repo root. `docs/index.html` links to the graph with relative paths, so a **copy** of the three files above must also live at `docs/graphify-out/` (linking with `../` would escape the Pages root and 404).

After regenerating, sync the copy:

```bash
cp graphify-out/graph.html graphify-out/GRAPH_REPORT.md graphify-out/graph.json docs/graphify-out/
```

This top-level `graphify-out/` remains the source of truth (`--update` runs read/write here); `docs/graphify-out/` is a publish-only mirror.

## Regenerating

```bash
/graphify . --update       # re-extract only new/changed files
/graphify .                # full rebuild
```

`kb-core/include/vmlinux.h` — a vendored BTF header with thousands of kernel struct definitions that otherwise dominate every god-node and community list with zero project-specific signal — is excluded automatically via [`.graphifyignore`](../.graphifyignore) at the repo root. Remember to re-sync `docs/graphify-out/` after regenerating (see above).
